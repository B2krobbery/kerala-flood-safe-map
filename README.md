# Kerala Flood Safe Interactive Map

An interactive flood safety mapping system for Kerala designed to improve disaster awareness, emergency preparedness, and flood-risk visualization.

## Features
- Flood risk classification
- District-based emergency information
- Relief shelter details
- Emergency helpline access
- Disaster preparedness guidance

## Purpose
Kerala experiences frequent flood-related disasters. This prototype explores how interactive mapping tools can improve public safety and awareness.

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub Pages

## Future Improvements
- Real-time rainfall data
- Clickable map districts
